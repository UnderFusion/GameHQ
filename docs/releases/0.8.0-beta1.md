# GameHQ 0.8.0 Beta 1 — Clip audio and cumulative fixes

Thank you to the community member who reported silent clips recorded while playing through Playnite, and to everyone helping test these fixes.

**Public pre-release for testing. This is not a stable release.** GameHQ 0.7.9 remains the Latest stable release, and the in-app updater offers this beta only when **Include beta versions** is on. These notes collect all changes since 0.7.9, including the 0.7.10 betas.

## Clip audio repair

- Desktop audio recording starts by default. An old internal workaround left **System audio** off by default, so clips could contain video only. The setting remains available in Settings > Replay.
- Windows playback formats are converted to a standard stereo format supported by the recording encoder instead of silently losing the audio track.
- If System audio is on but Windows audio cannot be captured, GameHQ retries and then tells you why no clip was saved, instead of saving a clip without sound.
- Quiet moments are recorded as silence, so the audio track stays complete and sound after a quiet stretch stays in sync with the picture.
- An explicitly saved choice to disable recording audio remains respected. Desktop recording includes sound playing through the default Windows output device, which can include other apps; it does not record the microphone.
- Tests decode saved clips to check audible stereo across segment changes and quiet stretches, and a real Windows playback-to-clip check passed on a test PC. Audio missing from an older clip cannot be recovered by this update.

## Other improvements since 0.7.9

- Optional beta updates: enable **Include beta versions** in Settings > General or About to receive beta releases. It is off by default. Each beta now identifies itself separately so the updater can offer the next one.
- Settings mouse scrolling no longer jumps back to the focused control when the window or a popup returns focus.
- Controller navigation repeats stop when GameInput reports the release or the controller is unplugged while a direction is held.
- Controller shortcuts work more reliably in games launched outside Steam, including games started from Playnite, when Windows stops delivering a connected DualSense through the normal input path. GameHQ temporarily reads that controller directly and returns to normal delivery when it recovers.
- Playnite games remain recognized when Playnite cannot identify the game's process.
- Windows Xbox mode with Playnite can use the verified game session for screenshots and clips when the Xbox shell holds the foreground.
- GameHQ notifications stay visible to you but are excluded from screenshots and whole-screen recordings. Notifications from other apps may still appear.

## Install and check

1. Close GameHQ using the tray icon's **Quit** command.
2. Run `GameHQ-0.8.0-win64-setup.exe` to update an installed copy, or extract the Portable ZIP into its own folder.
3. Keep **GameHQ Playnite Integration 0.4.13** if it is already installed; this beta does not require a new plugin build.
4. Check that **Settings > About** shows **0.8.0-beta1**. The separate About / What's New dialog shows the base version **0.8.0**.
5. Open **Settings > Replay** and make sure **System audio** is turned on. New installs have it on, but if you turned it off earlier, that choice is kept.
6. Start a game, let sound play and save a new clip. Play the file from its folder and confirm that its audio is audible.

## Known limitations

- Not yet confirmed with the reporter's game and playback device. Please report whether new clips have sound.
- System audio records the default Windows output device. A game assigned to a different output in Windows sound settings is not included in clips.
- Xbox mode support still needs confirmation on a PC running that mode. A game that takes exclusive control of a controller may still prevent background shortcuts.
- Windows binaries are not Authenticode-signed; Windows SmartScreen may show an Unknown Publisher warning.
- New release-note text uses English fallback where a reviewed translation is not yet available. Existing interface translations are unchanged.
