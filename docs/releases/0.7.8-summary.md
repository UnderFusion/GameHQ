# GameHQ 0.7.8 — short summary

- The overlay now works much more reliably over borderless games: it stays above the game and captures controller input for overlay navigation on supported GameInput paths.
- On supported GameInput paths, overlay navigation no longer controls the game, and the controller is handed back cleanly when you close it.
- Opening and closing the overlay with the PS button is faster and more reliable.
- Replay clips are never overwritten and can be saved right after recording starts.
- New controller mapping presets, assignable per controller and per game.
- GameHQ remembers your last page, filters, overlay category and selected capture, and restores its window correctly on any monitor.
- Separate interface and overlay scaling, plus louder capture sounds with their own volume control.
- Update notes in your language, with better diagnostics for troubleshooting.

Compatibility: controller isolation varies by game and input path; DSX switching remains partially verified.
