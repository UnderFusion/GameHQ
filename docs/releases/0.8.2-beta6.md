# GameHQ 0.8.2 Beta 6

This pre-release fixes small game icons and detection of windowed Steam games launched from Playnite. It includes the changes from Beta 5.

## Game icons

- Some games showed a tiny icon in the corner of an empty square (#42). This happened when the game's executable has no large 256-pixel icon. Windows then returns the small icon in the corner of a large transparent image. GameHQ now crops that icon and scales it to fill the square.
- Icons already in your library are extracted again once after the update.

## Playnite and Steam games

- With **Capture** set to **Any games**, a windowed Steam game launched from Playnite was not captured (#43). Playnite starts Steam games through Steam, so it cannot tell GameHQ which process is the game. GameHQ now accepts a game window when its program is inside that game's installation folder and started during the Playnite launch.
- A program that was already running before the launch, or two running games sharing one folder, are still not treated as a game. Fullscreen games were not affected.
- The replay-cache folder does not affect whether a game is detected.

## Testing and known limitations

Automated tests covered the icon crop with padded, full-size, centered and empty icons, and the Playnite matching rules for Steam launches, reconnects, earlier processes, other folders and shared folders. Existing integration, capture-target and icon refresh tests passed.

- The Steam launch fix was not tested with a real Playnite and Steam launch. Please tell us whether your game is now captured in **Any games**.
- A game started from Steam directly, not from Playnite, still needs to be fullscreen or whitelisted when it runs in a window.
- The limitations listed for Beta 5 still apply: partial mouse pointer verification, AMD-only encoder handles and one unreproduced test crash.

## Downloads and verification

Choose **Setup** for an installed copy or **Portable** for a no-install copy extracted into its own folder. Enable **Include beta versions** to receive beta updates in GameHQ.

The Windows binaries are unsigned and may show Unknown Publisher or SmartScreen warnings. The release manifest uses the production Ed25519 signature. GameHQ core is GPL-3.0-only. The Playnite integration and public protocol remain MIT-licensed.
