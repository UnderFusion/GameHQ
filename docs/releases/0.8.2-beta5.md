# GameHQ 0.8.2 Beta 5

This pre-release adds separate mouse cursor settings for screenshots and replays, and reduces the resources kept when switching between games. It includes the changes from Beta 4.

## Mouse cursor settings

- **Settings > Capture > Show mouse cursor** controls whether screenshots include the Windows mouse pointer. It is off by default, as in Beta 3. Beta 4 screenshots showed the pointer (#41).
- **Settings > Replay > Show mouse cursor** controls whether replays include it. It is on by default. A change applies to newly recorded video without restarting the recording.
- The two settings work independently. Taking a screenshot never changes the pointer in an ongoing recording. Cursors and crosshairs drawn by the game itself are always kept.
- Windows 10 before version 2004 always captures the pointer, so these settings are hidden there.

## Resource use

- On PCs with more than one GPU, GameHQ stopped retrying a hardware encoder that already refused the recording settings. Some encoders keep Windows handles after every refused attempt, so each switch between games kept about four handles. On the test system this dropped to about one per switch, which Windows itself keeps for each capture target.

## Testing and known limitations

Automated tests used isolated, non-activated Windows test windows on one system with an NVIDIA RTX 5090, an AMD GPU and a 4K HDR display, in SDR and HDR. All four combinations of the cursor settings were checked for the capture setting Windows reports, game-drawn crosshairs, replay continuity and stable resource use over repeated screenshots.

- The Windows pointer itself was confirmed visually only for the default combination (screenshot off, replay on). Please tell us whether the other combinations show or hide the pointer as set.
- On PCs whose only hardware encoder is the AMD encoder, about three Windows handles per game switch can remain. Reports from AMD systems are welcome.
- One automated test run crashed once during development and could not be reproduced in later recorded runs. Two test-only defects that fit it were fixed; the cause is not proven.
- Real games, Playnite launches, game audio routing, the overlay, controllers and displays with different scaling still depend on your feedback.
- Windows 11 rounds the bottom corners of framed windows, so a framed game's bottom client corners can show a few black pixels.

## Downloads and verification

Choose **Setup** for an installed copy or **Portable** for a no-install copy extracted into its own folder. Enable **Include beta versions** to receive beta updates in GameHQ.

The Windows binaries are unsigned and may show Unknown Publisher or SmartScreen warnings. The release manifest uses the production Ed25519 signature. GameHQ core is GPL-3.0-only. The Playnite integration and public protocol remain MIT-licensed.
