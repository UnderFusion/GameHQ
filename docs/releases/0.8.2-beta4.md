# GameHQ 0.8.2 Beta 4

This pre-release adds automatic background capture and game pinning, and captures only the game's own window content. It includes the changes from Beta 3.

## Background capture and pinning

- **Settings > Capture > Background capture** keeps capturing the last active game when you switch to another app. It is off by default, so capture still follows the foreground game unless you turn it on.
- The tray menu adds **Pin Current Game**, **Select Capture Target** when several eligible games are running, and **Return to Automatic Capture**. A pinned game stays the capture target for screenshots and replays until you unpin it, close it or restart it.
- The tray tooltip shows when the target is a pinned game, a background game or paused. A minimized target pauses and resumes when it is restored.

## Window content only

- Screenshots and replays use the selected game's client area. The title bar, the taskbar, overlapping windows and desktop pixels no longer appear when the game is covered, framed, or partly off-screen.
- Moving a game window keeps the recording running. Resizing it restarts capture once at the new size.
- Replay previews are decoded from the saved clip, and the exporter refuses segments that changed after they were recorded.

## Recording fixes

- Recording keeps the reused hardware encoder from Beta 3 with the new window-content capture. Without this fix, SDR recordings would have fallen back to a new encoder for every segment.
- A replay that spans a static scene, such as a paused menu or loading screen, now saves at its full length when the hardware encoder is reused.

## Testing and known limitations

Automated tests used isolated, non-activated Windows test windows on one NVIDIA RTX 5090 system with a 4K HDR display. Screenshots and every decoded replay frame matched the selected window while it moved off-screen, sat behind other windows, resized, minimized and switched pins.

- Not yet tested with real games, Playnite launches, game audio routing, the overlay, a controller, displays with different scaling, or AMD GPUs. Your feedback on these is the purpose of this beta.
- Windows 11 rounds the bottom corners of framed windows, so a framed game's bottom client corners can show a few rounded pixels.
- While capture runs, each switch between pinned games keeps about four Windows handles until capture stops.

## Downloads and verification

Choose **Setup** for an installed copy or **Portable** for a no-install copy extracted into its own folder. Enable **Include beta versions** to receive beta updates in GameHQ.

The Windows binaries are unsigned and may show Unknown Publisher or SmartScreen warnings. The release manifest uses the production Ed25519 signature. GameHQ core is GPL-3.0-only. The Playnite integration and public protocol remain MIT-licensed.
