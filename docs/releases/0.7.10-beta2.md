# GameHQ 0.7.10 Beta 2 — Controller shortcuts in non-Steam games

**Public pre-release for testing. This is not a stable release.** GameHQ 0.7.9 stays the Latest release, and the in-app updater does not offer this beta. Install it manually. The app reports version 0.7.10, like Beta 1.

Use it with the **GameHQ Playnite Integration 0.4.13** pre-release (`playnite-v0.4.13`), unchanged since Beta 1. If you already installed plugin 0.4.13, keep it.

## What's new since Beta 1

- **Controller shortcuts in games launched outside Steam.** With some games started directly as an `.exe` (for example from Playnite), Windows stopped delivering a connected DualSense to GameHQ while the game had focus, so screenshot and clip shortcuts did nothing. GameHQ now notices that and reads the controller directly (read-only, it never changes the controller's settings). When normal delivery comes back, GameHQ switches back to it. It can take a few seconds after the game starts.
- **Playnite games are kept when Playnite cannot identify the game's process.** GameHQ used to ignore such a game; it now keeps it and still only trusts the game's own process or install folder.

Everything from Beta 1 is included: Xbox mode with Playnite, and GameHQ notifications kept out of screenshots.

## Known limitations

- This fix is not yet confirmed by the reporter. Please report whether shortcuts now work in games launched from Playnite.
- If a game takes exclusive control of the controller, GameHQ cannot read it directly either; the log will say so.
- Windows binaries are not Authenticode-signed; Windows SmartScreen may warn before Setup runs.

## Install

1. Close GameHQ (tray icon > Quit).
2. Run `GameHQ-0.7.10-win64-setup.exe`. It updates the installed copy in place, so Playnite keeps finding it.
3. Plugin: if Playnite does not already show **GameHQ Integration 0.4.13**, open `GameHQ_Playnite_Integration_0_4_13.pext` from the `playnite-v0.4.13` pre-release and restart Playnite.

## Check the versions

- GameHQ: **About** shows **0.7.10**. The Setup file name is the same as Beta 1, so use the Beta 2 download.
- Playnite: **Add-ons > Generic > GameHQ Integration** shows **Plugin version 0.4.13**, **GameHQ version 0.7.10** and **Connected**.

If shortcuts still fail, send `gamehq.log` (Settings > Advanced > Locations > Logs folder) right after trying, plus the game, the controller and whether it is connected by USB or Bluetooth.
