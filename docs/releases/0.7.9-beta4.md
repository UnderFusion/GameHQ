# GameHQ 0.7.9 Beta 4 — Controller and UI testing

**Public prerelease for external testing. This is not the final 0.7.9 release.** The app still reports version 0.7.9. Stable users can remain on 0.7.8; Beta 4 is not offered as Latest or through the stable updater.

## DualSense input path enabled for this beta

Beta 4 enables the bounded, read-only direct-HID Sony input path by default for testing. **Testers do not need to set an environment variable.** Raw Input remains the fallback. This is a Beta 4 validation choice, not the final 0.7.9 production-default decision.

Please test: **USB in-game screenshot + replay → unplug → Bluetooth without restarting GameHQ → screenshot + replay again.** If it fails, send `gamehq.log` with the steps and controller/game details below.

For diagnostic comparison, `GAMEHQ_SONY_HID_READER=0` disables the new path for that launch; `=1` enables it. These overrides are optional and GameHQ does not persist them on your machine.

## What's new since Beta 3

- Share saved screenshots and clips from the gallery, full-screen viewer or overlay, with controller navigation, pinned destinations and confirmation before duplicate sharing. Use Copy to clipboard, Telegram Desktop, Discord Desktop or Discord channel webhooks; GameHQ never signs in to your Discord account.
- New Settings > Sharing page with a master switch and individual destination controls. Optional add-ons from other programs are off by default. Webhook secrets are stored in Windows Credential Manager. The integrated Telegram account-login prototype is excluded from this public build.
- Reviewed Share and Sharing settings translations across all 15 translated languages.
- Screenshots default to JPEG at 90% quality for smaller files; PNG remains available, and an explicitly chosen format is preserved.
- Open screenshots full screen in the overlay and browse captures with L1/R1 or D-pad left/right. While a clip plays, left/right seeks it. Keyboard and mouse use the appropriate control hints.
- The gallery and overlay follow capture folders live: deleted files disappear, restored files reappear with their favorite state, and newly copied files appear without Rescan.
- Resizable sidebars in Main and Overlay, with independent Expanded, Auto and Collapsed modes. Main also has an animated Tools section and controller access to language selection and Support.
- Pin games to keep them above other games, with remembered pins and animated reordering.
- Live Overlay options for outer margins, panel spacing, interface size, thumbnail size and control hints, with a reset button.
- Mark screenshots and clips as favorites directly in the full-screen viewers; Main's viewer has smaller margins.
- Separate switches for capture-request, Steam Input conflict and controller-hidden notifications, plus mouse dismissal without taking focus from your game.

## Fixes

- Removed a controller-topology refresh involved in the reported disconnect crash. In-game unplug/replug still needs external confirmation on this build.
- Capture menus, Share and Overlay options take priority over video controls.
- Resetting UI settings updates sidebar state and pinned-game order immediately.
- Starting another GameHQ copy no longer removes or takes over the installed copy's Start with Windows entry.
- Full-screen viewers keep a valid selection when favorites change or files disappear; collapsed sidebar controls and language menus retain predictable controller navigation.
- Repaired the complete test build and added regressions for sidebar navigation, language menus, toast input and favorite removal.

## Previous beta fixes included

Beta 4 also includes the Beta 1–3 fixes: corrected DualSense Bluetooth stick/button parsing and L3/R3, USB-to-Bluetooth fallback, faster backup-path input, editable mapping presets, faster overlay close after held input, and Steam Input conflict/controller-hidden guidance. Existing Bluetooth mappings are unchanged by the new Beta 4 build default.

## External testing

Please check controller disconnect/reconnect during active capture or replay, USB-to-Bluetooth switching without restarting GameHQ, screenshot/replay shortcuts while the game is foreground, and your normal Share destinations. These scenarios remain acceptance checks rather than claims of completed hardware testing.

For reports, include your controller model, USB/Bluetooth transport, Steam Input/DSX/HidHide configuration, game/window mode, steps and GameHQ log. Portable logs: `gamehq-data\logs\gamehq.log`; installed logs: `%APPDATA%\GameHQ\GameHQ\logs\gamehq.log`.
