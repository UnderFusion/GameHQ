# GameHQ 0.7.10 Beta 1 — Xbox mode with Playnite, cleaner screenshots

**Public pre-release for testing. This is not a stable release.** GameHQ 0.7.9 stays the Latest release, and the in-app updater does not offer this beta. Install it manually.

Use it together with the **GameHQ Playnite Integration 0.4.13** pre-release (`playnite-v0.4.13`). Playnite's automatic add-on updates keep offering 0.4.12 until this combination is confirmed.

## What's new

- **Windows Xbox mode (full screen experience) with Playnite.** Windows holds back startup apps until you first switch to the desktop, so after booting straight into Xbox mode GameHQ could be missing. Plugin 0.4.13 now checks again 15, 45 and 90 seconds after Playnite starts and when a game starts, and starts GameHQ if it is not running. When the Xbox shell holds the foreground, GameHQ uses the game Playnite started for screenshots and clips.
- **GameHQ notifications no longer appear in screenshots.** The notice that the previous screenshot was saved could be captured in the next screenshot. Notifications still appear on your screen. Screen recorders and streaming apps that capture the whole screen no longer show them either.

## Known limitations

- Xbox mode support has not yet been confirmed on a PC running Xbox mode. Please report whether it works.
- Pop-ups from other apps (Windows, Steam, Discord) can still appear in screenshots.
- Windows binaries are not Authenticode-signed; Windows SmartScreen may warn before Setup runs.

## Install

1. Close GameHQ (tray icon > Quit).
2. Run `GameHQ-0.7.10-win64-setup.exe`. It updates the installed copy in place, so Playnite keeps finding it.
3. In Playnite, open the `GameHQ_Playnite_Integration_0_4_13.pext` file (double-click it, or drag it onto Playnite) and restart Playnite.
4. If you use the Portable build instead, open Playnite > Add-ons > Generic > GameHQ Integration and set the GameHQ path to the Portable `GameHQ.exe`.

## Check the versions

- GameHQ: **About** in the sidebar shows **0.7.10**.
- Playnite: **Add-ons > Generic > GameHQ Integration** shows **Plugin version 0.4.13**, **GameHQ version 0.7.10**, the GameHQ path you expect, and **Connected**. If it shows an older GameHQ version, the plugin is pointed at another copy: set the path to the beta.

If something fails, send `gamehq.log` (Settings > Advanced > Locations > Logs folder) and Playnite's `extensions.log`.
