# GameHQ 0.8.2 Beta 3

**Draft for release review.** This beta focuses on replay reliability, lower resource use and a more responsive library. It includes the changes from Beta 2.

## Recording and memory

- Replay recording can reuse one hardware H.264 encoder across segments. In a 1080p30, 14 Mbps test on an NVIDIA RTX 5090, this used 115 MB less private memory and kept the Windows handle count steady across segments. Results depend on the GPU, driver and recording settings.
- Recording can absorb brief encoder stalls and fall back to the per-segment encoder if reuse fails. Replay export recovers video frames and audio samples that Windows sometimes skips at the ends of valid segments.
- GameHQ releases Windows capture resources when capture stops and avoids repeating window work when you switch games. The tray icon distinguishes active recording from screenshot-only capture.

## Responsiveness and updates

- The library scans changed folders in the background, adds new captures without refreshing every gallery, and builds screenshot thumbnails without holding up the interface.
- Controller delivery and local integration messages use bounded queues. Settings avoid disk writes when values stay the same.
- GameHQ clears an update offer when a release is withdrawn and lets capture resume when update preparation is cancelled or fails.
- Packages use Qt 6.11.3 and FFmpeg 7.1.5 with fixes for Qt Network and Qt Multimedia. [Qt Network advisory](https://www.qt.io/blog/security-advisory-cve-2026-105946) ? [Qt Multimedia advisory](https://www.qt.io/blog/security-advisory-cve-2026-8461)

## Known limitations

- Long recordings with H.264 encoder reuse still need validation on AMD GPUs. The NVIDIA benchmark measures that test system only. GameHQ uses its per-segment encoder when hardware reuse is unavailable or fails.
- The full Beta 2 to Beta 3 installer and updater lifecycle, live capture, and physical controller checks are pending release acceptance.

## Downloads and verification

When this beta is published, Setup is the recommended download for an installed copy. Portable is the no-install alternative and should be extracted into its own folder. The updater offers betas when **Include beta versions** is enabled. Windows may show an Unknown Publisher or SmartScreen warning for the unsigned beta binaries.
