## Acceptance and exclusions

The owner explicitly confirms native wired DualSense visibility, isolation, responsive repeated PS toggles and neutral return in Indiana Jones and the Great Circle Borderless, plus satisfactory early replay saving. These are owner observations, not a laboratory matrix covering every game or API. The exact executable hash and number of physical cycles were not supplied.

DSX switching has no new specific physical receipt and remains partial. An optional single retest consists of opening the overlay in the existing DSX configuration, changing the previously problematic output/provider mode once, closing the overlay and trying one game action; return the modes, approximate time, symptom and diagnostics. Native acceptance need not be repeated.

The owner skipped the forced-termination experiment and accepted its residual risk. Old protected canonical owner blockers have provenance restrictions; obsolete package references are historical bookkeeping debt and are superseded by this candidate. They are not evidence of a product failure or permission to manufacture PASS results. Unreported preset/capture/hardware checklist cases are not silently marked passed.

The release gate found a repeatable native test failure when an external application took focus after a topmost-game overlay cycle. Temporary tracing showed no foreground WinEvent for that transition, although the existing watcher observed the new foreground and released input. The bounded correction reuses the same lifetime policy from that watcher after verified acquisition, dismissing the overlay without restoring foreground to the game. Null transitions, same-game windows and denied acquisition keep their existing behavior. The stack-order assertions now wait for the existing cross-process demotion/repair transition instead of sampling it immediately; the trace showed correct order at the next 50 ms probe. Temporary tracing was removed; the native suite covers all four topmost-game exit paths plus normal focus, denial and handoff behavior. This final correction has automated evidence; earlier owner observations are not relabeled as a physical test of it.

The expanded notes also exposed a test-fixture assumption: adding a duplicate to eight valid sections triggered the section-count guard first. The duplicate-ID fixture now uses exactly two duplicate sections, preserving the validator's existing limits.

Deliberately excluded: universal isolation across XInput/Raw Input/HID/Steam Input/DSX; a guaranteed fix for the original unreported 8BitDo View/Back case; universal physical-device correlation; guaranteed Windows border disappearance; verified abnormal-termination recovery; full translation of these new release notes; developer receiver tooling as a shipping user feature. Existing language support and installer/portable features already shipped in 0.7.7 are not presented as newly added.

## Version audit

`VERSION` is 0.7.8. CMake derives the application and updater versions from it. The launcher has no independent version string or VERSIONINFO resource; it forwards to the packaged application. The release-note source, manifest, generated bundle index and publication directory use 0.7.8. Package names and README text derive from the same value. Public historical release-note sources remain intact.

`packaging/public-app-version.txt` intentionally stays at 0.7.7: it controls the currently published download surface, not the candidate version. The minimum updater version is a compatibility floor, not the candidate version. Neither is advanced before publication. No public updater manifest is generated or signed during this local preparation. Historical development labels in engineering evidence remain historical, never intermediate public releases.

The complete user notes are in `0.7.8.md`; `0.7.8-summary.md` is derived from entries in those notes. The same full entries populate CHANGELOG and the canonical release-note source, with deterministic generated locale bundles/publication files and complete localized documents for all sixteen production locales (English fallback remains only a safety mechanism).
