# GameHQ 0.7.15 (2026-09-09)

> This document is the original **English (en-US)** release note. No reviewed Thai translation exists for this version, so the complete English text is published unchanged.

## Added

- Capture settings now let you request Windows capture-border suppression. The setting is on by default and applies to the next capture session without interrupting the current session or replay buffer.
- Capture settings explain the Windows border-suppression result without promising that a border is invisible. The new explanations use English until the planned translation pass.
