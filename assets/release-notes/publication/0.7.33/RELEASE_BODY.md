# GameHQ 0.7.33 (2026-09-19)

## Fixed

- Controller buttons now mean the same thing no matter which Windows input API delivers them. The triggers and stick clicks of a wired DualSense were reported as unnamed buttons by one interface and as named controls by another, so a saved shortcut could stop matching after pressing certain buttons.
