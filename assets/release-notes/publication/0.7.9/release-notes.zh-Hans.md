# GameHQ 0.7.9 (2026-10-02)

## 亮点

- 分享你的捕获内容。可从图库、全屏查看器或叠加层将截图或片段发送到 Telegram Desktop、Discord、Discord 频道或剪贴板，无需通过 GameHQ 登录任何账户。
- DualSense 通过 USB 和 Bluetooth 连接都稳定可靠。Bluetooth 连接下的按键和摇杆可被正确读取，在有线和 Bluetooth 之间切换不再需要重启，游戏中拔下手柄也不会再导致 GameHQ 崩溃。被 HidHide 隐藏的 DualSense 和 DualShock 4 手柄，在 GameHQ 获准通过 HidHide 后仍可使用。
- 可自定义的叠加层。实时生效的“叠加界面选项”面板可设置边距、间距、缩略图大小、界面大小和操作提示；侧边栏可以展开、收起、设为“自动”或调整大小。
- 在叠加层中全屏查看。可在游戏上方全屏打开截图，用 L1/R1 逐一浏览截图和片段，并直接在查看器中标记收藏。
- 图库与你的文件保持同步。在文件资源管理器中删除、还原或复制的捕获内容会立即出现或消失；游戏还可以置顶在列表最上方。
- 截图文件更小。现在默认使用 90% 质量的 JPEG，仍可选择 PNG。
- 对通知的控制更多。“已收到捕获请求”、“Steam Input 冲突”和“手柄被隐藏”这三种提示可分别控制，使用鼠标时还可以提前关闭通知。
- 更多界面支持用手柄操作，包括语言选择器、“支持”、“工具”以及“分享”的每个步骤。

## 分享

- 分享任意已保存的截图或片段：在捕获内容上按方块键并选择“分享”，点击捕获内容缩略图上的“分享”图标，或使用全屏查看器中的“分享”按钮。在图库、查看器和叠加层中的操作方式相同，并且完全支持手柄操作（叉键确认，圆圈键返回）。
- Telegram Desktop 会打开它自己的聊天选择器，并只带上这一个文件。GameHQ 从不登录 Telegram。
- 选择 Discord 会复制捕获内容并打开 Discord，你可以将其粘贴到任意聊天中。GameHQ 从不登录 Discord。
- “Discord 频道”通过在“设置 → 分享”中添加的 Webhook 链接，将捕获内容直接发布到频道。可以将最常用的频道置顶。发布的内容会以 Webhook 的身份显示，而不是以你的 Discord 账户身份显示，链接保存在 Windows 凭据管理器中。
- “复制到剪贴板”可作为单独的分享目标使用。
- 从叠加层分享时，Telegram 或 Discord 会显示在游戏前方，方便你完成发送。
- 只有在服务确认送达后，GameHQ 才会显示“已发送”；将同一捕获内容再次分享到同一位置前，也会先询问你。
- “设置 → 分享”是一个新页面，每个分享目标都有独立的开关；关闭某个目标会保留其配置。
- 你电脑上的其他程序可以添加自己的分享目标。此功能默认关闭：请在“设置 → 分享”中开启“允许来自其他程序的附加组件”，然后重启 GameHQ。

## 叠加层

- 在截图上按叉键可全屏打开。按 L1/R1 或方向键左/右可逐一浏览截图和片段（片段会全屏播放），按圆圈键会返回捕获内容条，并停在你最后浏览的那一项上。在片段上按叉键仍会在预览中播放，之后按左/右可拖动进度。
- 侧边栏切换按钮上方的齿轮图标可打开“叠加界面选项”：开启或关闭操作提示、四个外边距（最低可设为 0）、界面大小（现在包括 75% 和 90%）、缩略图大小，以及侧边栏、缩略图和预览之间的间距。更改会实时显示并被记住；“重置叠加界面布局”可恢复默认值。支持手柄、鼠标和键盘操作。

## 图库与界面

- 置顶游戏：将鼠标悬停在侧边栏中的游戏上并点击图钉，或将手柄光标移到该游戏上并按三角键。置顶的游戏在主窗口和叠加层中都会固定在列表顶部。
- 在全屏查看器中，按三角键（或你为收藏分配的按键）可将当前显示的截图或片段标记为收藏，再按一次则取消收藏。心形图标会显示收藏状态，也可以点击。
- 主窗口和叠加层中的侧边栏可以收起。一个按钮可在“展开”（默认）、“自动”和“收起”之间循环切换。“自动”模式在你浏览时显示窄图标栏，当你移入侧边栏时会展开完整侧边栏。每个窗口会分别记住各自的选择。
- 拖动侧边栏边缘可使其变窄或变宽；双击边缘可恢复默认宽度。
- “工具”上方的小箭头可将“帮助”、“关于”、“支持”和语言选择器折叠起来，只保留“设置”和侧边栏模式按钮。

## 变更与改进

- 截图默认以 90% 质量的 JPEG 格式保存，而不再是 PNG，因此每个文件会小好几倍。如果你从未更改过格式，会自动改用 JPEG；PNG 仍可在“设置 → 捕获”中选择。
- 图库和叠加层会实时跟随你的捕获文件夹。在文件资源管理器中删除的捕获内容会立即消失；从回收站还原后，它会连同收藏标记和历史记录一起完整恢复。复制到捕获文件夹中的新文件无需“重新扫描”即可显示。已打开的查看器会停留在它正在显示的捕获内容上，删除确认始终会删除其中指明的那项捕获内容。
- “设置 → 通知与声音”为“已收到捕获请求”、“Steam Input 冲突”和“手柄被隐藏”这三种提示提供了单独的开关。
- 使用鼠标时，通知会显示一个 X 以便提前关闭，鼠标悬停在通知上时它会保持显示。仅使用手柄游玩时没有任何变化；隐藏光标的游戏也绝不会显示 X。
- 警告通知会在屏幕上停留 10 秒，并带有警示图标。
- 新增的分享、界面、手柄和通知文本已在所有支持的界面语言中经过审校。
- 主窗口全屏查看器的边距减半，因此捕获内容显示得更大。
- 一旦你使用键盘或鼠标，全屏查看器的提示就会切换为方向键和 Esc 键。
- 主侧边栏中的语言选择器、“支持 GameHQ”和“工具”组现在可以用手柄访问。侧边栏收起时，语言选择器仍以图标形式可用。
- 在叠加层中，捕获内容菜单、“分享”和“叠加界面选项”现在优先于视频播放，因此按叉键会选择菜单项，而不会播放其后方的片段。

## 问题修复

- DualSense 通过 Bluetooth 连接：GameHQ 现在能正确读取摇杆和按键。此前 Bluetooth 报告的读取位置偏移了一个字节，导致摇杆上/下被识别为左/右，按键也被误读。USB 连接不受影响。
- 对于由 GameHQ 直接读取的 DualSense 和 DualShock 4 手柄，L3 和 R3（摇杆按下）现在可以正常使用。
- 在 GameHQ 运行时将手柄在 USB 和 Bluetooth 之间切换，不会再导致手柄无响应。
- 游戏内捕获期间拔下手柄不会再导致 GameHQ 崩溃。
- 使用 Windows 游戏杆备用路径的手柄，快速轻按不会再被漏掉。
- 如果在叠加层打开前已按住某个按键，关闭叠加层时不会再卡住。
- “设置 → 输入 → 映射预设”：“分配”列表现在会显示并编辑在“正在编辑的预设”中选择的预设。此前，被游戏使用或未分配给当前手柄的预设无法编辑，连按两次等自定义映射也无法移除或还原。
- “随 Windows 启动”：另一个 GameHQ 副本（便携版，或使用独立设置的副本）不会再移除或接管已安装副本的启动项，此前这可能导致已安装的 GameHQ 在重启后无法启动。

## 手柄与兼容性

- 与以前一样，Sony 手柄通过标准的 Windows 输入路径读取。
- 通过 USB 或 Bluetooth 连接、被 HidHide 隐藏的 DualSense 或 DualShock 4 会被检测并报告。在 HidHide 中允许 GameHQ 后（“自动修复”即可完成此操作），GameHQ 会像 DSX 一样直接读取该手柄，同时该手柄对游戏仍保持隐藏。
- 当隐藏手柄的驱动程序（HidHide，随 DSX、DS4Windows 或 reWASD 安装）对 GameHQ 隐藏你的手柄时，主窗口顶部会显示一条横幅说明情况，并提供“自动修复”、“设置”和“以后再说”。
- GameHQ 不会安装或移除 HidHide，也不会更改它隐藏哪些手柄。如果你选择“自动修复”，它只会将 GameHQ 添加到 HidHide 的允许应用程序中。
- Steam Input 指引：当 Steam 游戏正在运行，且某个 GameHQ 快捷键使用了 Create / Share 或 PS 时，GameHQ 会说明 Steam Input 也可能将该按键发送给游戏，并提供按钮来打开该游戏的 Steam 手柄布局或 Steam 的控制器设置。GameHQ 从不读取或更改 Steam 的设置。此指引可以关闭，也可以按游戏隐藏。

## 已知限制

- 叠加层能否阻止手柄输入传到游戏，取决于游戏本身及其读取手柄的方式。使用 GameInput 的有线 DualSense 已经过充分测试；对于 XInput、Raw Input、直接 HID、Steam Input 或虚拟手柄，则无法保证。
- 对于 Telegram Desktop 和 Discord，GameHQ 会打开相应应用，由你在其中完成发送；GameHQ 无法得知你是否真的发送了捕获内容，因此绝不会对它们显示“已发送”。使用 Discord 时，需要你自己将捕获内容粘贴到聊天中。
- 上传到 Discord 频道的文件受该服务器文件大小上限的限制。
- 部分游戏在失去焦点时会暂停或作出反应，例如分享后 Telegram 或 Discord 显示到前台时。Windows 或其他捕获应用可能会使黄色录制边框保持可见。
