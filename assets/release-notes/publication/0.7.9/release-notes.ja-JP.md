# GameHQ 0.7.9 (2026-09-25)

## 修正

- Bluetooth 接続の DualSense：GameHQ のメニューでスティックとボタンが正しく読み取られるようになりました。以前は左スティックの上下が左右として認識されたり、一部のボタンが反応しなかったりすることがありました。USB 接続には影響はありませんでした。
- GameHQ に直接接続した DualSense および DualShock 4 コントローラーで、L3 と R3（スティック押し込み）が使えるようになりました。

## 診断

- 各 Sony コントローラーが送信するレポート形式をログに記録するようになり、コントローラーの問題を診断しやすくなりました。
