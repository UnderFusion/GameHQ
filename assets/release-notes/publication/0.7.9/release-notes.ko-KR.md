# GameHQ 0.7.9 (2026-10-02)

## 주요 변경 사항

- 캡처 공유. 갤러리, 전체 화면 뷰어, 오버레이에서 스크린샷이나 클립을 Telegram Desktop, Discord, Discord 채널 또는 클립보드로 보낼 수 있으며, GameHQ를 통해 어디에도 로그인할 필요가 없습니다.
- USB와 Bluetooth 모두에서 안정적인 DualSense. Bluetooth 연결 시 버튼과 스틱이 올바르게 읽히고, 유선과 Bluetooth를 전환할 때 더 이상 다시 시작할 필요가 없으며, 게임 중에 컨트롤러를 분리해도 GameHQ가 더 이상 충돌하지 않습니다. HidHide가 숨긴 DualSense 및 DualShock 4 컨트롤러도 HidHide에서 GameHQ를 허용하면 계속 사용할 수 있습니다.
- 원하는 대로 조정하는 오버레이. 오버레이 옵션 패널에서 여백, 간격, 썸네일 크기, 인터페이스 크기, 조작 안내를 실시간으로 설정할 수 있으며, 사이드바는 펼치거나 접거나 자동으로 설정하거나 크기를 조절할 수 있습니다.
- 오버레이의 전체 화면 보기. 게임 위에 스크린샷을 전체 화면으로 열고, L1/R1로 스크린샷과 클립을 차례로 넘겨 보며, 뷰어에서 즐겨찾기를 지정할 수 있습니다.
- 파일 변경을 따라가는 갤러리. 파일 탐색기에서 삭제, 복원, 복사한 캡처가 즉시 나타나거나 사라지며, 게임을 목록 맨 위에 고정할 수 있습니다.
- 더 작은 스크린샷 파일. 이제 품질 90%의 JPEG가 기본값이며, PNG도 계속 사용할 수 있습니다.
- 알림을 더 세밀하게 제어. 캡처 요청, Steam Input 충돌, 컨트롤러 숨김 알림을 각각 따로 설정할 수 있으며, 마우스 사용자는 알림을 일찍 닫을 수 있습니다.
- 언어 선택기, GameHQ 후원, 도구, 모든 공유 단계를 포함해 더 많은 인터페이스를 컨트롤러로 사용할 수 있습니다.

## 공유

- 저장된 스크린샷이나 클립을 공유할 수 있습니다. 캡처에서 Square를 누르고 ‘공유’를 선택하거나, 캡처 타일의 공유 아이콘을 클릭하거나, 전체 화면 뷰어의 ‘공유’ 버튼을 사용하세요. 갤러리, 뷰어, 오버레이에서 모두 똑같이 작동하며 컨트롤러만으로도 완전히 사용할 수 있습니다(Cross로 선택, Circle로 뒤로 가기).
- Telegram Desktop은 해당 파일 하나로 자체 채팅 선택 화면을 엽니다. GameHQ는 Telegram에 로그인하지 않습니다.
- Discord는 캡처를 복사하고 Discord를 열어 원하는 채팅에 붙여 넣을 수 있게 합니다. GameHQ는 Discord에 로그인하지 않습니다.
- Discord 채널은 설정 › 공유에서 추가한 웹훅 링크를 통해 캡처를 채널에 바로 게시합니다. 자주 사용하는 채널은 고정할 수 있습니다. 게시물은 내 Discord 계정이 아닌 웹훅으로 표시되며, 링크는 Windows 자격 증명 관리자에 저장됩니다.
- ‘클립보드에 복사’를 별도의 공유 대상으로 사용할 수 있습니다.
- 오버레이에서 공유하면 Telegram 또는 Discord가 게임 위 전면으로 나타나므로 전송을 마칠 수 있습니다.
- GameHQ는 서비스가 전달을 확인한 경우에만 ‘보냈습니다’로 표시하며, 같은 캡처를 같은 곳에 두 번 공유하기 전에 확인을 요청합니다.
- 설정 › 공유는 공유 대상마다 스위치가 있는 새 페이지입니다. 공유 대상을 꺼도 해당 구성은 유지됩니다.
- PC의 다른 프로그램이 자체 공유 대상을 추가할 수 있습니다. 이 기능은 기본적으로 꺼져 있습니다. 설정 › 공유에서 ‘다른 프로그램의 애드온 허용’을 켜고 GameHQ를 다시 시작하세요.

## 오버레이

- 스크린샷에서 Cross를 누르면 전체 화면으로 열립니다. L1/R1 또는 D-pad 왼쪽/오른쪽으로 스크린샷과 클립을 차례로 넘기고(클립은 전체 화면으로 재생됨), Circle을 누르면 마지막으로 보던 항목에서 캡처 목록으로 돌아갑니다. 클립에서 Cross를 누르면 이전처럼 미리 보기에서 재생되며, 이때 왼쪽/오른쪽으로 탐색할 수 있습니다.
- 사이드바 전환 버튼 위의 톱니바퀴를 누르면 오버레이 옵션이 열립니다. 조작 안내 켜기/끄기, 바깥쪽 여백 4개(0까지), 인터페이스 크기(이제 75%와 90% 포함), 썸네일 크기, 사이드바·썸네일·미리 보기 사이의 간격을 설정할 수 있습니다. 변경 사항은 실시간으로 표시되고 기억되며, ‘오버레이 레이아웃 초기화’로 기본값을 복원할 수 있습니다. 컨트롤러, 마우스, 키보드로 사용할 수 있습니다.

## 갤러리 및 인터페이스

- 게임 고정: 사이드바에서 게임 위에 마우스를 올리고 핀을 클릭하거나, 컨트롤러 커서를 게임으로 옮기고 Triangle을 누르세요. 고정된 게임은 기본 창과 오버레이 모두에서 목록 맨 위에 유지됩니다.
- 전체 화면 뷰어에서 Triangle(또는 즐겨찾기에 할당한 버튼)을 누르면 표시 중인 스크린샷이나 클립을 즐겨찾기로 지정하고, 다시 누르면 해제합니다. 하트가 상태를 표시하며 클릭할 수도 있습니다.
- 기본 창과 오버레이에서 사이드바를 접을 수 있습니다. 버튼을 누를 때마다 펼침(기본값), 자동, 접힘이 차례로 바뀝니다. ‘자동’에서는 둘러보는 동안 좁은 아이콘 레일이 표시되고, 그 위로 이동하면 전체 사이드바가 열립니다. 각 창은 자체 선택을 기억합니다.
- 사이드바 가장자리를 끌어 너비를 좁히거나 넓힐 수 있으며, 가장자리를 두 번 클릭하면 기본 너비로 돌아갑니다.
- 도구 위의 작은 화살표를 누르면 도움말, 정보, GameHQ 후원, 언어 선택기가 접히고 설정과 사이드바 모드 버튼만 남습니다.

## 변경 및 개선 사항

- 이제 스크린샷이 기본적으로 PNG 대신 품질 90%의 JPEG로 저장되어 파일마다 크기가 몇 배 작아집니다. 형식을 변경한 적이 없다면 자동으로 JPEG가 적용되며, PNG는 설정 › 캡처에서 계속 선택할 수 있습니다.
- 갤러리와 오버레이가 캡처 폴더의 변경 사항을 실시간으로 반영합니다. 파일 탐색기에서 삭제한 캡처는 즉시 사라지고, 휴지통에서 복원하면 즐겨찾기 표시와 기록이 그대로 유지된 채 돌아옵니다. 캡처 폴더에 복사한 새 파일은 다시 검색하지 않아도 나타납니다. 열려 있는 뷰어는 표시 중인 캡처를 계속 표시하며, 삭제 확인에서는 항상 확인 창에 표시된 캡처가 삭제됩니다.
- 설정 › 알림 및 소리에 ‘캡처 요청 받음’, ‘Steam Input 충돌’, ‘컨트롤러 숨김’ 알림을 위한 개별 스위치가 있습니다.
- 마우스를 사용할 때는 알림에 X가 표시되어 일찍 닫을 수 있으며, 알림 위에 마우스를 올리면 화면에 계속 표시됩니다. 컨트롤러만으로 플레이할 때는 달라지는 것이 없으며, 커서를 숨기는 게임에서는 X가 표시되지 않습니다.
- 경고 알림은 화면에 10초 동안 표시되며 주의 아이콘이 함께 나타납니다.
- 새로운 공유, 인터페이스, 컨트롤러, 알림 텍스트를 지원되는 모든 인터페이스 언어에서 검토했습니다.
- 기본 창의 전체 화면 뷰어 여백이 절반으로 줄어 캡처가 더 크게 표시됩니다.
- 키보드나 마우스를 사용하면 바로 전체 화면 뷰어의 안내가 화살표 키와 Esc 키로 바뀝니다.
- 기본 사이드바의 언어 선택기, GameHQ 후원, 도구 그룹을 컨트롤러로 선택할 수 있습니다. 접힌 사이드바에서도 언어 선택기는 아이콘으로 계속 사용할 수 있습니다.
- 이제 오버레이에서 캡처 메뉴, 공유, 오버레이 옵션이 동영상 재생보다 우선하므로, Cross를 누르면 뒤에 있는 클립이 재생되지 않고 메뉴 항목이 선택됩니다.

## 버그 수정

- Bluetooth로 연결한 DualSense: 이제 GameHQ에서 스틱과 버튼이 올바르게 읽힙니다. Bluetooth 리포트를 1바이트 어긋나게 읽어 스틱의 위/아래가 왼쪽/오른쪽으로 인식되고 버튼이 잘못 읽혔습니다. USB는 영향을 받지 않았습니다.
- 이제 GameHQ가 직접 읽는 DualSense 및 DualShock 4 컨트롤러에서 L3와 R3(스틱 누르기)가 작동합니다.
- GameHQ 실행 중에 컨트롤러를 USB와 Bluetooth 간에 전환해도 더 이상 컨트롤러가 응답하지 않는 상태가 되지 않습니다.
- 게임 내 캡처 중에 컨트롤러를 분리해도 더 이상 GameHQ가 충돌하지 않습니다.
- Windows 조이스틱 대체 경로를 사용하는 컨트롤러에서 짧게 누른 입력이 더 이상 누락되지 않습니다.
- 오버레이가 열리기 전부터 버튼을 누르고 있던 경우에도 오버레이를 닫을 때 더 이상 멈추지 않습니다.
- 설정 › 입력 › 매핑 프리셋: 이제 ‘할당’ 목록에 ‘편집 중인 프리셋’에서 선택한 프리셋이 표시되고 편집됩니다. 이전에는 게임에서 사용하는 프리셋이나 이 컨트롤러에 할당되지 않은 프리셋을 편집할 수 없었고, 두 번 누르기 같은 사용자 지정 매핑을 제거하거나 되돌릴 수 없었습니다.
- Windows와 함께 시작: 다른 GameHQ 사본(포터블 빌드 또는 자체 설정을 사용하는 사본)이 더 이상 설치된 사본의 시작 항목을 제거하거나 가로채지 않습니다. 이 문제로 인해 재시작 후 설치된 GameHQ가 시작되지 않을 수 있었습니다.

## 컨트롤러 및 호환성

- Sony 컨트롤러는 이전과 마찬가지로 표준 Windows 입력 경로를 통해 읽습니다.
- USB 또는 Bluetooth로 연결된 DualSense나 DualShock 4가 HidHide에 의해 숨겨져 있으면 이를 감지하여 알려 줍니다. HidHide에서 GameHQ를 허용하면(‘자동으로 수정’이 이 작업을 수행합니다) 컨트롤러가 게임에서는 계속 숨겨진 상태로, GameHQ가 DSX와 같은 방식으로 컨트롤러를 직접 읽습니다.
- 컨트롤러 숨김 드라이버(DSX, DS4Windows, reWASD와 함께 설치되는 HidHide)가 GameHQ에서 컨트롤러를 숨기면 기본 창 상단에 표시줄이 나타나 상황을 설명하고 ‘자동으로 수정’, ‘설정’, ‘나중에’ 버튼을 제공합니다.
- GameHQ는 HidHide를 설치하거나 제거하지 않으며, HidHide가 숨기는 컨트롤러도 변경하지 않습니다. ‘자동으로 수정’을 선택하면 HidHide의 허용된 애플리케이션에 GameHQ를 추가하는 작업만 수행합니다.
- Steam Input 안내: Steam 게임이 실행 중이고 GameHQ 단축키가 Create / Share 또는 PS 버튼을 사용하는 경우, GameHQ는 Steam Input도 해당 버튼을 게임에 보낼 수 있다고 설명하고 게임의 Steam 컨트롤러 레이아웃이나 Steam 컨트롤러 설정을 여는 버튼을 제공합니다. GameHQ는 Steam 설정을 읽거나 변경하지 않습니다. 이 안내는 끄거나 게임별로 숨길 수 있습니다.

## 알려진 제한 사항

- 오버레이가 컨트롤러 입력을 게임과 분리할 수 있는지는 게임과 해당 게임이 컨트롤러를 읽는 방식에 따라 다릅니다. GameInput을 사용하는 유선 DualSense는 충분히 테스트되었으며, XInput, Raw Input, 직접 HID, Steam Input, 가상 컨트롤러에서는 보장되지 않습니다.
- Telegram Desktop과 Discord에서는 GameHQ가 앱을 열고, 전송은 해당 앱에서 직접 마칩니다. GameHQ는 실제로 캡처를 보냈는지 확인할 수 없으므로 이 경우 ‘보냈습니다’로 표시하지 않습니다. Discord에서는 캡처를 직접 채팅에 붙여 넣어야 합니다.
- Discord 채널 업로드는 서버의 파일 크기 제한을 받습니다.
- 일부 게임은 포커스를 잃으면(예: 공유 후 Telegram이나 Discord가 전면으로 나올 때) 일시 정지되거나 반응할 수 있습니다. Windows나 다른 캡처 앱 때문에 노란색 녹화 테두리가 계속 표시될 수 있습니다.
