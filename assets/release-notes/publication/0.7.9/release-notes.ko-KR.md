# GameHQ 0.7.9 (2026-09-25)

## 수정 사항

- 블루투스 DualSense: 이제 GameHQ 메뉴에서 스틱과 버튼이 올바르게 인식됩니다. 이전에는 왼쪽 스틱을 위나 아래로 밀면 왼쪽이나 오른쪽으로 인식되거나 일부 버튼이 반응하지 않을 수 있었습니다. USB 연결은 영향을 받지 않았습니다.
- GameHQ에 직접 연결된 DualSense 및 DualShock 4 컨트롤러에서 이제 L3와 R3(스틱 누르기)가 작동합니다.

## 진단

- 이제 로그에 각 Sony 컨트롤러가 보내는 리포트 형식이 기록되어 컨트롤러 문제를 더 쉽게 진단할 수 있습니다.
