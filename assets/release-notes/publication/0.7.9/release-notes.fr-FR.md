# GameHQ 0.7.9 (2026-09-25)

## Corrections

- DualSense en Bluetooth : les sticks et les boutons sont désormais lus correctement dans les menus de GameHQ. Auparavant, pousser le stick gauche vers le haut ou le bas pouvait être interprété comme gauche ou droite, et certains boutons ne répondaient pas. L’USB n’était pas concerné.
- L3 et R3 (appui sur les sticks) fonctionnent désormais sur les manettes DualSense et DualShock 4 connectées directement à GameHQ.

## Diagnostic

- Le journal indique désormais le format de rapport envoyé par chaque manette Sony, ce qui facilite le diagnostic des problèmes de manette.
