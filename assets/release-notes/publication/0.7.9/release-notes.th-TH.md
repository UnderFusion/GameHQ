# GameHQ 0.7.9 (2026-09-25)

## การแก้ไข

- DualSense ผ่านบลูทูธ: ตอนนี้ GameHQ อ่านค่าก้านอนาล็อกและปุ่มในเมนูได้ถูกต้องแล้ว ก่อนหน้านี้การดันก้านซ้ายขึ้นหรือลงอาจถูกอ่านเป็นซ้ายหรือขวา และบางปุ่มไม่ตอบสนอง การเชื่อมต่อแบบ USB ไม่ได้รับผลกระทบ
- L3 และ R3 (การกดก้านอนาล็อก) ใช้งานได้แล้วบนคอนโทรลเลอร์ DualSense และ DualShock 4 ที่เชื่อมต่อกับ GameHQ โดยตรง

## การวินิจฉัย

- ตอนนี้บันทึกจะระบุรูปแบบรายงานที่คอนโทรลเลอร์ Sony แต่ละตัวส่งมา ช่วยให้วินิจฉัยปัญหาคอนโทรลเลอร์ได้ง่ายขึ้น
