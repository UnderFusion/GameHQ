# GameHQ 0.7.10 (2026-10-08)

## Исправления ошибок

- На снимках экрана больше не появляются собственные уведомления GameHQ, например сообщение о том, что предыдущий снимок сохранён. На экране уведомления по-прежнему отображаются.
- Режим Xbox в Windows (полноэкранный режим) с Playnite: если Windows сообщает, что активное окно — приложение Xbox, а не игра, запущенная из Playnite, GameHQ всё равно распознаёт игру, и снимки экрана и клипы работают. Используйте вместе с GameHQ Playnite Integration 0.4.13.

## Изменения и улучшения

- Программы для записи и стриминга, захватывающие весь экран, тоже больше не показывают уведомления GameHQ.

## Известные ограничения

- Всплывающие окна других приложений, например уведомления Windows, Steam или Discord, по-прежнему могут попадать на снимки экрана.
- Поддержка режима Xbox новая и ещё не подтверждена на ПК, работающем в режиме Xbox.
