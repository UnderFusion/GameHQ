# GameHQ 0.7.10 (2026-10-08)

## 问题修复

- 截图中不再包含 GameHQ 自己的通知，例如提示上一张截图已保存的通知。这些通知仍会显示在你的屏幕上。
- Windows Xbox 模式（全屏体验）配合 Playnite：当 Windows 报告的活动窗口是 Xbox 应用而不是从 Playnite 启动的游戏时，GameHQ 仍能识别该游戏，截图和剪辑都可正常使用。请与 GameHQ Playnite Integration 0.4.13 一起使用。

## 变更与改进

- 捕获整个屏幕的录屏和直播应用也不会再显示 GameHQ 的通知。

## 已知限制

- 其他应用的弹窗（例如 Windows、Steam 或 Discord 的通知）仍可能出现在截图中。
- Xbox 模式支持是新功能，尚未在运行 Xbox 模式的电脑上得到确认。
