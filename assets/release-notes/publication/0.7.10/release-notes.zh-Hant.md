# GameHQ 0.7.10 (2026-10-08)

## 錯誤修正

- 螢幕擷取畫面不再包含 GameHQ 自己的通知，例如提示上一張擷取畫面已儲存的通知。這些通知仍會顯示在您的螢幕上。
- Windows Xbox 模式（全螢幕體驗）搭配 Playnite：當 Windows 回報的作用中視窗是 Xbox 應用程式，而不是從 Playnite 啟動的遊戲時，GameHQ 仍能辨識該遊戲，因此螢幕擷取畫面與短片都能正常運作。請搭配 GameHQ Playnite Integration 0.4.13 使用。

## 變更與改進

- 擷取整個螢幕的錄影與直播應用程式也不會再顯示 GameHQ 的通知。

## 已知限制

- 其他應用程式的快顯視窗（例如 Windows、Steam 或 Discord 的通知）仍可能出現在螢幕擷取畫面中。
- Xbox 模式支援為新功能，尚未在執行 Xbox 模式的電腦上獲得確認。
