# GameHQ 0.7.10 (2026-10-08)

## 不具合の修正

- スクリーンショットに GameHQ 自身の通知（前のスクリーンショットを保存したことを知らせる通知など）が写り込まなくなりました。通知は引き続き画面に表示されます。
- Playnite と Windows の Xbox モード（フルスクリーン エクスペリエンス）：Playnite から起動したゲームではなく Xbox アプリがアクティブ ウィンドウとして報告される場合でも、GameHQ はゲームを認識し、スクリーンショットとクリップが機能します。GameHQ Playnite Integration 0.4.13 と組み合わせて使用してください。

## 変更点と改善点

- 画面全体をキャプチャする録画アプリや配信アプリにも、GameHQ の通知は映らなくなりました。

## 既知の制限

- Windows、Steam、Discord の通知など、他のアプリのポップアップは引き続きスクリーンショットに写り込むことがあります。
- Xbox モードへの対応は新しい機能で、Xbox モードで動作する PC ではまだ確認されていません。
