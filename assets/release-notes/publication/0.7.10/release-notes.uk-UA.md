# GameHQ 0.7.10 (2026-10-08)

## Виправлення помилок

- На знімках екрана більше не з'являються власні сповіщення GameHQ, наприклад повідомлення про те, що попередній знімок збережено. На екрані сповіщення й надалі відображаються.
- Режим Xbox у Windows (повноекранний режим) із Playnite: якщо Windows повідомляє, що активне вікно — застосунок Xbox, а не гра, запущена з Playnite, GameHQ однаково розпізнає гру, тож знімки екрана й кліпи працюють. Використовуйте разом із GameHQ Playnite Integration 0.4.13.

## Зміни та покращення

- Програми для запису та стримінгу, які захоплюють увесь екран, теж більше не показують сповіщення GameHQ.

## Відомі обмеження

- Спливні вікна інших застосунків, наприклад сповіщення Windows, Steam або Discord, і далі можуть потрапляти на знімки екрана.
- Підтримка режиму Xbox нова й ще не підтверджена на ПК, що працює в режимі Xbox.
