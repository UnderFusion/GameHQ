# GameHQ 0.7.10 (2026-10-08)

## Correcciones de errores

- Las capturas de pantalla ya no incluyen las notificaciones propias de GameHQ, como el aviso de que se guardó la captura anterior. Las notificaciones siguen apareciendo en tu pantalla.
- Modo Xbox de Windows (experiencia a pantalla completa) con Playnite: cuando Windows indica que la ventana activa es la aplicación Xbox en lugar de un juego iniciado desde Playnite, GameHQ sigue reconociendo el juego, así que las capturas y los clips funcionan. Úsalo junto con GameHQ Playnite Integration 0.4.13.

## Cambios y mejoras

- Las aplicaciones de grabación y de streaming que capturan toda la pantalla tampoco muestran ya las notificaciones de GameHQ.

## Limitaciones conocidas

- Las ventanas emergentes de otras aplicaciones, como las notificaciones de Windows, Steam o Discord, pueden seguir apareciendo en las capturas.
- La compatibilidad con el modo Xbox es nueva y todavía no se ha confirmado en un PC con el modo Xbox.
