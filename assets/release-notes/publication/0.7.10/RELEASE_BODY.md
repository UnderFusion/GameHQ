# GameHQ 0.7.10 (2026-10-08)

## Bug Fixes

- Screenshots no longer include GameHQ's own notifications, such as the notice that the previous screenshot was saved. The notifications still appear on your screen.
- Windows Xbox mode (full screen experience) with Playnite: when Windows reports the Xbox app as the active window instead of a game started from Playnite, GameHQ still recognizes the game, so screenshots and clips work. Use it together with GameHQ Playnite Integration 0.4.13.

## Changes & Improvements

- Screen recorders and streaming apps that capture the whole screen no longer show GameHQ notifications either.

## Known Limitations

- Pop-ups from other apps, such as Windows, Steam or Discord notifications, can still appear in screenshots.
- Xbox mode support is new and has not yet been confirmed on a PC running Xbox mode.
