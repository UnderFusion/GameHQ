# GameHQ 0.7.10 (2026-10-08)

## การแก้ไขข้อบกพร่อง

- ภาพหน้าจอจะไม่มีการแจ้งเตือนของ GameHQ เอง เช่น การแจ้งว่าบันทึกภาพหน้าจอก่อนหน้าแล้ว ติดมาอีกต่อไป การแจ้งเตือนยังคงแสดงบนหน้าจอของคุณตามปกติ
- โหมด Xbox ของ Windows (ประสบการณ์แบบเต็มหน้าจอ) กับ Playnite: เมื่อ Windows รายงานว่าแอป Xbox เป็นหน้าต่างที่ใช้งานอยู่แทนเกมที่เปิดจาก Playnite GameHQ จะยังคงจดจำเกมได้ ภาพหน้าจอและคลิปจึงทำงานได้ ใช้ร่วมกับ GameHQ Playnite Integration 0.4.13

## การเปลี่ยนแปลงและการปรับปรุง

- แอปบันทึกหน้าจอและแอปสตรีมที่จับภาพทั้งหน้าจอจะไม่แสดงการแจ้งเตือนของ GameHQ อีกต่อไปเช่นกัน

## ข้อจำกัดที่ทราบ

- ป๊อปอัปจากแอปอื่น เช่น การแจ้งเตือนของ Windows, Steam หรือ Discord อาจยังปรากฏในภาพหน้าจอได้
- การรองรับโหมด Xbox เป็นฟีเจอร์ใหม่และยังไม่ได้รับการยืนยันบนพีซีที่ใช้โหมด Xbox
