# GameHQ 0.7.10 (2026-10-08)

## Corrections de bugs

- Les captures d'écran n'incluent plus les notifications de GameHQ, comme l'avis indiquant que la capture précédente a été enregistrée. Les notifications restent visibles à l'écran.
- Mode Xbox de Windows (expérience plein écran) avec Playnite : lorsque Windows indique l'application Xbox comme fenêtre active au lieu d'un jeu lancé depuis Playnite, GameHQ reconnaît quand même le jeu, et les captures d'écran et les clips fonctionnent. À utiliser avec GameHQ Playnite Integration 0.4.13.

## Modifications et améliorations

- Les logiciels d'enregistrement et de streaming qui capturent tout l'écran n'affichent plus non plus les notifications de GameHQ.

## Limitations connues

- Les fenêtres contextuelles d'autres applications, comme les notifications de Windows, Steam ou Discord, peuvent encore apparaître dans les captures.
- La prise en charge du mode Xbox est nouvelle et n'a pas encore été confirmée sur un PC en mode Xbox.
