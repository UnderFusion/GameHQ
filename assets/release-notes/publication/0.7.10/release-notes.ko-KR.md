# GameHQ 0.7.10 (2026-10-08)

## 버그 수정

- 이제 스크린샷에 이전 스크린샷이 저장되었다는 알림 같은 GameHQ 자체 알림이 포함되지 않습니다. 알림은 화면에 계속 표시됩니다.
- Playnite와 Windows Xbox 모드(전체 화면 환경): Windows가 Playnite에서 시작한 게임 대신 Xbox 앱을 활성 창으로 보고해도 GameHQ가 게임을 인식하므로 스크린샷과 클립이 작동합니다. GameHQ Playnite Integration 0.4.13과 함께 사용하세요.

## 변경 및 개선 사항

- 화면 전체를 캡처하는 녹화 및 스트리밍 앱에도 이제 GameHQ 알림이 표시되지 않습니다.

## 알려진 제한 사항

- Windows, Steam, Discord 알림 같은 다른 앱의 팝업은 여전히 스크린샷에 나타날 수 있습니다.
- Xbox 모드 지원은 새 기능이며 아직 Xbox 모드로 실행 중인 PC에서 확인되지 않았습니다.
