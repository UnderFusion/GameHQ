# GameHQ 0.7.36 (2026-09-21)

> This document is the original **English (en-US)** release note. No reviewed Turkish translation exists for this version, so the complete English text is published unchanged.

## Changed

- Mapping presets now sit directly above Assignments on the Input settings page. Choosing the preset a controller or game uses and editing the individual bindings it contains belong together, so the two sections are no longer separated by the profile and gesture settings.
