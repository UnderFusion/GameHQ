# GameHQ 0.7.7 (2026-09-07)

## 新增

- GameHQ 现已提供十六种界面语言。首次启动时会跟随 Windows 的语言，你也可以在设置中另选一种。
- 切换语言会立即应用于整个应用程序，包括叠加层和托盘菜单，无需重启 GameHQ。你的选择会被记住。
- 安装程序现在会以你的语言运行，并把该选择传递给 GameHQ 的首次启动，安装程序与应用程序不会再各说各话。
- Playnite 扩展和启动器的错误对话框同样已本地化。
- 只要这些说明存在对应的译文，更新内容就会以你的语言显示；如果没有译文，则显示完整的英文文本，而不会中英混杂。

## 变更

- 日期、数字和数量现在跟随所选语言，而不是系统默认设置。

## 已知限制

- GameHQ 仍是未签名的测试版，因此运行安装程序时 Windows 可能会提示发布者未知。
