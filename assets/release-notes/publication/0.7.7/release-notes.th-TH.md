# GameHQ 0.7.7 (2026-09-07)

## เพิ่มใหม่

- ขณะนี้ GameHQ รองรับภาษาส่วนติดต่อผู้ใช้ 16 ภาษา เมื่อเปิดครั้งแรกจะใช้การตั้งค่าภาษาของ Windows และเลือกภาษาอื่นได้ในการตั้งค่า
- การเปลี่ยนภาษามีผลทันทีทั่วทั้งแอปพลิเคชัน รวมถึงโอเวอร์เลย์และเมนูในพื้นที่แจ้งเตือน โดยไม่ต้องเริ่ม GameHQ ใหม่ ระบบจะจดจำภาษาที่เลือกไว้
- ตัวติดตั้งทำงานเป็นภาษาที่เลือกและส่งต่อภาษานั้นไปยังการเปิด GameHQ ครั้งแรก ตัวติดตั้งกับแอปพลิเคชันจึงไม่ใช้ภาษาต่างกันอีกต่อไป
- ส่วนขยาย Playnite และกล่องข้อความแจ้งข้อผิดพลาดของตัวเรียกใช้งานได้รับการแปลด้วยเช่นกัน
- มีอะไรใหม่จะแสดงเป็นภาษาที่เลือกเมื่อมีบันทึกฉบับแปล หากไม่มี ระบบจะแสดงข้อความภาษาอังกฤษฉบับเต็มแทนโดยไม่ปะปนหลายภาษา

## เปลี่ยนแปลง

- วันที่ ตัวเลข และจำนวนรายการใช้รูปแบบตามภาษาที่เลือกแทนค่าเริ่มต้นของระบบ

## ข้อจำกัดที่ทราบ

- GameHQ ยังเป็นรุ่นเบต้าที่ไม่ได้เซ็นชื่อ ดังนั้น Windows อาจเตือนว่าผู้เผยแพร่ไม่รู้จักเมื่อคุณเรียกใช้ตัวติดตั้ง
