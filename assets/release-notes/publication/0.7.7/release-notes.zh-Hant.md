# GameHQ 0.7.7 (2026-09-07)

## 新增

- GameHQ 現已提供十六種介面語言。首次啟動時會跟隨 Windows 的語言，也可在設定中另選一種。
- 切換語言會立即套用到整個應用程式，包括遊戲內嵌介面與通知區域功能表，不需要重新啟動 GameHQ。此選擇會被記住。
- 安裝程式現在會以所選語言執行，並將該選擇傳遞給 GameHQ 的首次啟動，安裝程式與應用程式不會再各說各話。
- Playnite 擴充功能與啟動器的錯誤對話方塊同樣已在地化。
- 只要這些說明有對應的譯文，更新內容就會以所選語言顯示；若沒有譯文，則顯示完整的英文文字，而不會中英夾雜。

## 變更

- 日期、數字與數量現在會跟隨所選語言，而不是系統預設值。

## 已知限制

- GameHQ 仍是未簽署的測試版，因此執行安裝程式時 Windows 可能會警告發行者不明。
