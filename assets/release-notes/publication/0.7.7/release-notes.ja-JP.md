# GameHQ 0.7.7 (2026-09-07)

## 追加

- GameHQ の表示言語が 16 言語になりました。初回起動時は Windows の言語に従い、設定から別の言語を選ぶこともできます。
- 言語を切り替えると、オーバーレイや通知領域のメニューを含むアプリ全体に即座に反映され、GameHQ を再起動する必要はありません。選んだ言語は記憶されます。
- セットアップがあなたの言語で実行され、その選択が GameHQ の初回起動に引き継がれるようになりました。インストーラーとアプリの言語が食い違うことはありません。
- Playnite 拡張機能とランチャーのエラーダイアログも各言語に対応しました。
- 更新内容は、翻訳版が用意されている場合はあなたの言語で表示されます。用意されていない場合は、言語が混在することなく英語の全文が表示されます。

## 変更

- 日付、数値、件数がシステム既定ではなく、選択した言語に従うようになりました。

## 既知の制限

- GameHQ は引き続き署名なしのベータ版です。そのため、セットアップを実行すると Windows が発行元不明の警告を表示することがあります。
