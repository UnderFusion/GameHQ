# GameHQ 0.7.7 (2026-09-07)

## Добавлено

- GameHQ теперь доступен на шестнадцати языках интерфейса. При первом запуске он использует язык Windows, а другой можно выбрать в настройках.
- Смена языка действует сразу во всём приложении, включая оверлей и меню в трее, без перезапуска GameHQ. Ваш выбор запоминается.
- Установщик теперь работает на вашем языке и передаёт этот выбор первому запуску GameHQ, поэтому установщик и приложение больше не расходятся.
- Расширение для Playnite и диалоги ошибок программы запуска также переведены.
- Раздел «Что нового» отображается на вашем языке всегда, когда есть переведённая версия этих заметок. Если её нет, показывается полный английский текст, а не смесь языков.

## Изменено

- Даты, числа и счётные формы теперь следуют выбранному языку, а не системной настройке.

## Известные ограничения

- GameHQ по-прежнему является неподписанной бета-версией, поэтому при запуске программы установки Windows может предупредить о неизвестном издателе.
