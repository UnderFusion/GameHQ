# GameHQ 0.8.0 (2026-10-26)

## スペシャルサンクス

- [Console Overlay for Playnite](https://github.com/galcn10/ConsoleOverlay) の作者である [@galcn10](https://github.com/galcn10) さんに心から感謝します。GameHQ のテスト、貴重なフィードバックの共有、そして優れた Playnite 連携の開発をありがとうございました。そのご支援のおかげで、GameHQ 0.8.0 はより良いものになりました！

## 主な変更点

- 自動アップデート検出を改善。GameHQ は起動のたびに直後と、実行中は 1 時間ごとに新しいリリースを確認するようになり、アップデートにずっと早く気付けるようになりました。
- クリップにゲーム自体の音声を録音できるようになりました。新しい音声ソース「ゲーム音声」では、ゲームがどのデバイス（ヘッドホン、Bluetooth、HDMI、スピーカー）で再生されていても GameHQ がゲームの音声を録音し、Discord や Spotify などの他のアプリの音は含めません。
- 音声の録音に問題があると検出して知らせるようになりました。選択した音声ソースを録音できない場合は、無音のクリップを黙って保存するのではなく、リプレイバッファが停止し、その理由と代わりに選ぶべきソースを表示します。GameHQ が音声ソースを勝手に切り替えることはありません。
- 音声と映像が同期したままになります。ロード画面、一時停止、長いフリーズの後に保存したクリップでもタイミングが正しく保たれ、ゲームが解像度を変更するとリプレイバッファが自動的に再起動します。
- HDR のスクリーンショットが止まらなくなりました。一時停止中のゲームや静止したメニューを HDR で撮影したスクリーンショットはすぐに保存されます。フレームがまったく届かない場合でも、数秒後に正常に失敗として終了し、次に押したときは正しく動作します。
- コントローラーでの削除がより安全になりました。削除の確認では、×ボタンでハイライトされているボタンが押され、○ボタンでキャンセルされるようになりました。以前は「キャンセル」がハイライトされていても、×ボタンでファイルが削除されることがありました。
- 削除しても元のファイルは守られます。GameHQ が作成したキャプチャを削除すると、ごみ箱に移動されるようになったため、復元できます。監視フォルダー内のファイルが削除されることはありません。

## 新機能

- 設定 › リプレイ › 音声ソース で「ゲーム音声」、「デスクトップ音声」、「オフ」を選べます。Windows 11 では「ゲーム音声」が既定です。「デスクトップ音声」は Windows の既定の出力で流れるすべての音（他のアプリを含む）を録音し、以前のバージョンの Windows ではこちらが既定です。
- 「ゲーム音声」は Windows 標準のアプリごとの音声キャプチャを使用し、ゲームのプロセスには一切触れません。以前のバージョンでシステム音声を意図的にオフにしていた場合は、オフのままになります。
- ベータ版の更新（任意）: 設定 › 一般 と「GameHQについて」に新しく追加された「ベータ版を含める」スイッチで、アップデーターがベータ版を提供できるようになります。既定ではオフなので、安定版のインストールには安定版の更新のみが届きます。
- GameHQ がクラッシュしたときは、問題の診断に役立つ小さなクラッシュダンプをログフォルダーに保存しようとします。何もアップロードされません。Windows によって即座に終了させられる場合など、一部のクラッシュでは、ダンプが作成されないまま GameHQ が終了することがあります。
- 保存したスクリーンショットや起動時のエラーについて、より詳しい情報がログに記録されるようになりました。そのため、ログファイル 1 つで問題の報告内容を把握できることが多くなります。

## 修正と改善

- デスクトップ音声を既定でオフにしていた古い内部設定が原因で、クリップが無音になることはなくなりました。
- Windows のどの再生形式の音声も正しく変換されるようになり、音声トラックが失われなくなりました。
- 静かな場面は無音として録音されるため、静かな時間が続いた後の音声も映像とずれません。
- ゲームを再起動したり別のゲームに切り替えたりしたときに、ゲーム音声の録音がより確実に再開されるようになりました。
- リプレイバッファのうち、保存に失敗した部分や読み戻せない部分は除外されるため、保存したクリップが壊れることはありません。
- スクリーンショットの保存通知など、GameHQ 自体の通知がスクリーンショットや画面全体の録画・配信に映り込まなくなりました。
- スクリーンショットが同じファイル名の別の画像に置き換えられた場合、次回のライブラリのスキャンでサムネイルが新しくなります。
- キャプチャフォルダーをバックグラウンドでスキャンするため、大量のコレクションがあっても GameHQ の応答性が保たれます。
- ブラウザーやエディターなど、ゲームではないウィンドウがライブラリにゲームとして表示されなくなりました。
- 一括削除では、確認が表示されている間は選択内容が固定されるため、バックグラウンドでのコントローラー操作によって削除されるファイルが変わることはありません。
- オーバーレイの削除ダイアログは、開いている間はコントローラーの入力を受け取り、オーバーレイが非表示になると閉じます。
- オーバーレイは、応答しなくなったウィンドウを待たずにスキップします。
- GameHQ に戻った後にマウスでスクロールしても、設定画面が先頭に戻らなくなりました。
- コントローラーのマッピングエディターで「組み込みの既定値」を選んだりプリセットを削除したりしても、プリセットの選択が固まらなくなりました。

## コントローラーと Playnite

- Playnite から起動したローカルゲームなど、Steam 以外で起動したゲームでもコントローラーのショートカットが引き続き機能します。ゲームにフォーカスがある間に Windows が接続中の DualSense を GameHQ に渡さなくなった場合、GameHQ はコントローラーを読み取り専用で直接読み取り、Windows が再び渡すようになると通常の入力に戻ります。
- ショートカットとボタン長押し時のリピートは、GameInput 経由で報告されたボタンの離しや、ボタンを押したままコントローラーを取り外した場合も含め、必ず同じ押下の離しで終了します。
- 完全に切断されたコントローラーは整理され、HidHide のチェックでインターフェースが遅くならなくなり、GameInput デバイスは変化があったときにのみ再チェックされます。
- Playnite がゲームのプロセスを特定できない場合でも、Playnite のゲームが認識されたままになります。
- Windows の Xbox フル スクリーン エクスペリエンス: Xbox のシェルが前面にあるとき、GameHQ はスクリーンショットとクリップに Playnite から起動したゲームを使用します。また、プレリリースとして別途提供されている GameHQ Playnite Integration 0.4.13 は、サインイン時に Xbox モードによって GameHQ の起動が遅れた場合にも GameHQ を起動します。

## 安定性と信頼性

- 未完了の録画のクリーンアップでは、GameHQ 自身が作成した一時ファイルのみを削除します。
- ゲームのキャプチャフォルダーは常にキャプチャフォルダーの中に収まります。
- ライブラリに重複したフォルダーパスが含まれていても起動に失敗しなくなり、代わりにそれらの項目が統合されます。
- GameHQ を起動できない場合は、その理由をお使いの言語で説明し、ログにも記録します。
- インストール版がすでに起動されたことがある場合でも、インストール版の GameHQ にポータブル版プロファイルをインポートできるようになりました。
- セキュリティを強化しました。DLL の読み込みをより安全にし、ローカル連携の接続をより厳しくチェックし、更新ファイルをより安全に扱います。
- アップデーターは初回起動が遅い場合にもより適切に対処し、中断されても記録が損なわれません。
- Telegram 共有の終了処理がより安全になりました。

## インストールと更新

- 0.7.9 からの更新: 現在のインストールに上書きして 0.8.0 のインストーラーを実行してください。
- インストーラー: 現在のユーザー向けにインストールし、インストール済みの 0.7.9 または以前のベータ版を置き換えます。
- ポータブル版: ZIP を新しいフォルダーに展開し、GameHQ.exe を実行します。
- 0.8.0 Beta 2、3、4 をテストした場合は、インストーラーまたは新しいポータブル版 ZIP で 0.8.0 をインストールしてください。これらのベータ版はアップデーターでは提供されていなかったためです。

## 既知の制限

- 「ゲーム音声」には Windows 11 が必要です。以前のバージョンの Windows では、GameHQ は「デスクトップ音声」を使用するため、既定の出力で再生されている他のアプリの音も録音されます。
- コントローラーを排他的に制御するゲームでは、引き続きバックグラウンドのショートカットが機能しない場合があります。
- Windows の Xbox フル スクリーン エクスペリエンスへの対応は、それを実行している PC でのテスターによる確認がまだ取れていません。
- Windows 用のバイナリは Authenticode 署名されていません。Windows SmartScreen で「不明な発行元」の警告が表示される場合があります。
