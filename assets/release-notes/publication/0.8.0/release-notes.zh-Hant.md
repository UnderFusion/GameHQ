# GameHQ 0.8.0 (2026-10-26)

## 特別感謝

- 衷心感謝 [Console Overlay for Playnite](https://github.com/galcn10/ConsoleOverlay) 的作者 [@galcn10](https://github.com/galcn10) 測試 GameHQ、分享寶貴的意見回饋，並打造了出色的 Playnite 整合。您的支持讓 GameHQ 0.8.0 變得更好！

## 重點

- 短片可以錄製遊戲本身的聲音了。透過新的「遊戲音訊」來源，無論遊戲透過哪種裝置播放聲音（耳機、Bluetooth、HDMI 或喇叭），GameHQ 都會錄下遊戲的聲音，並排除 Discord 或 Spotify 等其他應用程式。
- 現在會偵測並回報音訊錄製問題。如果所選的音訊來源無法錄製，重播緩衝區會停止並告訴您原因，以及應改選哪個來源，而不會悄悄儲存沒有聲音的短片。GameHQ 絕不會自行切換音訊來源。
- 聲音與畫面保持同步。在載入畫面、暫停或長時間停頓之後儲存的短片會保持正確的時間；遊戲變更解析度時，重播緩衝區會自動重新啟動。
- HDR 螢幕截圖不再卡住。在 HDR 下對暫停的遊戲或靜態選單擷取的螢幕截圖會立即儲存。如果完全沒有收到任何畫面，此次嘗試會在幾秒後正常結束為失敗，下次按下即可正常運作。
- 用控制器刪除更安全。在刪除確認中，叉鍵現在會按下目前反白的按鈕，圓圈鍵則會取消。先前即使反白的是「取消」，叉鍵也可能刪除檔案。

## 新功能

- 「設定 › 重播 › 音訊來源」提供「遊戲音訊」、「桌面音訊」和「關」。在 Windows 11 上預設為「遊戲音訊」。「桌面音訊」會錄製 Windows 預設輸出裝置上的所有聲音（包括其他應用程式），並且是較舊 Windows 版本上的預設選項。
- 「遊戲音訊」使用 Windows 內建的個別應用程式音訊擷取功能，絕不會觸碰遊戲處理程序。如果您在先前版本中刻意關閉了系統音訊，它會維持關閉。
- 可選擇的測試版更新：「設定 › 一般」和「關於」中新增「包含測試版」開關，可讓更新程式提供測試版。此開關預設為關閉，因此穩定版安裝只會收到穩定版更新。
- GameHQ 當機時，會嘗試在其記錄檔資料夾中儲存一個小型當機傾印檔，以協助診斷問題。不會上傳任何內容。部分當機（例如被 Windows 立即終止的情況）仍可能導致 GameHQ 在沒有傾印檔的情況下關閉。
- 記錄檔會記錄更多關於已儲存螢幕截圖和啟動失敗的詳細資訊，因此更常只需一個記錄檔就能釐清問題回報。

## 修正與改進

- 短片不再因為一項讓桌面音訊預設為關閉的舊內部設定而沒有聲音。
- 任何 Windows 播放格式的音訊都會正確轉換，不再遺失音軌。
- 安靜的時段會錄製為靜音，因此安靜一段時間後的聲音仍會與畫面對齊。
- 遊戲重新啟動或您切換遊戲時，遊戲音訊錄製能更可靠地重新開始。
- 重播緩衝區中儲存失敗或無法讀回的部分會被排除，因此不會破壞已儲存的短片。
- GameHQ 本身的通知（例如螢幕截圖已儲存的通知）不再出現在您的螢幕截圖中，也不會出現在全螢幕錄影和直播中。
- 如果螢幕截圖被另一張同檔名的圖片取代，下次掃描媒體庫時會為其產生新的縮圖。
- 擷取資料夾會在背景掃描，因此即使收藏量很大，GameHQ 仍能保持流暢回應。
- 瀏覽器、編輯器以及其他非遊戲的視窗，不再以遊戲的形式出現在您的媒體庫中。
- 大量刪除時，確認視窗開啟期間選取的項目會保持固定，因此背景的控制器操作無法變更要刪除的檔案。
- 遊戲內嵌介面的刪除對話方塊在開啟期間會接管控制器的輸入，並在遊戲內嵌介面隱藏時關閉。
- 遊戲內嵌介面會略過已停止回應的視窗，而不會等待它們。
- 切換回 GameHQ 後用滑鼠捲動時，「設定」不再跳回頂端。
- 在控制器對應編輯器中選擇「內建預設設定」或移除預設後，預設的選取不再卡住。

## 控制器與 Playnite

- 在 Steam 以外啟動的遊戲（例如從 Playnite 啟動的本機遊戲）中，控制器快速鍵仍可正常運作。當遊戲取得焦點時，若 Windows 停止將已連線的 DualSense 傳遞給 GameHQ，GameHQ 會以唯讀方式直接讀取該控制器，並在 Windows 恢復傳遞後回到一般輸入方式。
- 快速鍵和按住按鈕時的重複動作，一律會在同一次按壓放開時結束，包括透過 GameInput 回報的放開，以及在按住按鈕時拔除控制器的情況。
- 已永久中斷連線的控制器會被清除，HidHide 檢查不再拖慢介面，GameInput 裝置也只會在有變化時重新檢查。
- 即使 Playnite 無法識別遊戲的處理程序，仍能辨識出 Playnite 遊戲。
- Windows 的 Xbox 全螢幕體驗：當 Xbox 介面位於前景時，GameHQ 會使用從 Playnite 啟動的遊戲來擷取螢幕截圖和短片。此外，當 Xbox 模式在登入時延遲了 GameHQ 的啟動，另以預先發行版提供的 GameHQ Playnite Integration 0.4.13 也會啟動 GameHQ。

## 穩定性與可靠性

- 清除未完成的錄影時，只會移除 GameHQ 本身建立的暫存檔案。
- 遊戲擷取資料夾一律位於您的擷取資料夾內。
- 媒體庫包含重複的資料夾路徑時，啟動不再失敗，而是會合併這些項目。
- 如果 GameHQ 無法啟動，會以您的語言說明原因，並將原因保留在記錄檔中。
- 現在即使已安裝的複本已經啟動過，也能將可攜式設定檔匯入已安裝的 GameHQ。
- 強化安全性：更安全的 DLL 載入、對本機整合連線更嚴格的檢查，以及更安全的更新檔案處理。
- 更新程式更能應對首次啟動緩慢的情況，並在中斷時保持其記錄完整。
- Telegram 分享的關閉過程更加安全。

## 安裝與更新

- 從 0.7.9 更新：內建更新程式會提供 0.8.0，您也可以直接在目前的安裝上執行安裝程式。您的設定、媒體庫和擷取內容都會保留。
- 安裝程式：為目前使用者安裝，並取代已安裝的 0.7.9 或較早的測試版。
- 可攜式版本：將 ZIP 解壓縮到新資料夾，然後執行 GameHQ.exe。
- 如果您測試過 0.8.0 Beta 2、3 或 4，請使用安裝程式或全新的可攜式 ZIP 安裝 0.8.0，因為這些測試版並未透過更新程式提供。

## 已知限制

- 「遊戲音訊」需要 Windows 11。在較舊的 Windows 版本上，GameHQ 會使用「桌面音訊」，它也會錄製在預設輸出裝置上播放的其他應用程式。
- 獨占控制器的遊戲仍可能使背景快速鍵無法運作。
- 對 Windows 的 Xbox 全螢幕體驗的支援，尚未經測試人員在執行該體驗的 PC 上確認。
- Windows 執行檔未經 Authenticode 簽署；Windows SmartScreen 可能會顯示「未知的發行者」警告。
