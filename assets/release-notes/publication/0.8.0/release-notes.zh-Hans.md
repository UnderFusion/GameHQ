# GameHQ 0.8.0 (2026-10-26)

## 特别感谢

- 衷心感谢 [Console Overlay for Playnite](https://github.com/galcn10/ConsoleOverlay) 的作者 [@galcn10](https://github.com/galcn10) 测试 GameHQ、分享宝贵的反馈，并打造了出色的 Playnite 集成。你的支持让 GameHQ 0.8.0 变得更好！

## 亮点

- 片段可以录制游戏本身的声音了。借助新的“游戏音频”来源，无论游戏通过哪种设备播放声音（耳机、Bluetooth、HDMI 或扬声器），GameHQ 都会录下游戏的声音，并排除 Discord 或 Spotify 等其他应用。
- 现在会检测并报告音频录制问题。如果所选音频来源无法录制，回放缓冲区会停止并告诉你原因以及应改选哪个来源，而不会悄悄保存没有声音的片段。GameHQ 绝不会自行切换音频来源。
- 声音与画面保持同步。在加载画面、暂停或长时间卡顿之后保存的片段会保持正确的时间；游戏更改分辨率时，回放缓冲区会自动重新启动。
- HDR 截图不再卡住。在 HDR 下对暂停的游戏或静态菜单截图会立即保存。如果完全没有收到画面帧，此次尝试会在几秒后正常结束为失败，下一次按下即可正常截图。
- 用手柄删除更安全。在删除确认中，叉键现在会按下当前高亮的按钮，圆圈键则会取消。此前即使高亮的是“取消”，叉键也可能删除文件。
- 删除时会保护你的原始文件。删除由 GameHQ 创建的捕获内容时，现在会将其移到回收站，你可以随时还原。监视文件夹中的文件永远不会被删除。

## 新功能

- “设置 › 回放 › 音频来源”提供“游戏音频”、“桌面音频”和“关”三个选项。在 Windows 11 上默认使用“游戏音频”。“桌面音频”会录制 Windows 默认输出设备上的所有声音（包括其他应用），在较旧的 Windows 版本上为默认选项。
- “游戏音频”使用 Windows 自带的按应用音频捕获功能，绝不触碰游戏进程。如果你在早期版本中特意关闭了系统音频，它会保持关闭。
- 可选的测试版更新：“设置 › 常规”和“关于”中新增“包含测试版”开关，可让更新程序提供测试版。此开关默认关闭，因此稳定版安装只会收到稳定版更新。
- GameHQ 崩溃时，会尝试在其日志文件夹中保存一个小型崩溃转储，以帮助诊断问题。不会上传任何内容。某些崩溃（例如被 Windows 立即终止的情况）仍可能导致 GameHQ 在没有生成转储的情况下关闭。
- 日志会记录更多关于已保存截图和启动失败的详细信息，因此更多时候仅凭一个日志文件就足以弄清问题报告。

## 修复与改进

- 片段不再因一项让桌面音频默认处于关闭状态的旧内部设置而没有声音。
- 任何 Windows 播放格式的音频都会被正确转换，不再丢失音轨。
- 安静的时段会被录制为静音，因此一段安静时间之后的声音仍会与画面对齐。
- 游戏重新启动或你切换游戏时，游戏音频录制能更可靠地重新开始。
- 回放缓冲区中保存失败或无法读回的部分会被排除，因此不会损坏已保存的片段。
- GameHQ 自身的通知（例如截图已保存的提示）不再出现在你的截图中，也不会出现在全屏录制和直播中。
- 如果截图被另一张同名图片替换，下次扫描媒体库时会为其生成新的缩略图。
- 捕获文件夹会在后台扫描，因此即使收藏量很大，GameHQ 也能保持流畅响应。
- 浏览器、编辑器以及其他非游戏窗口不再作为游戏出现在你的媒体库中。
- 批量删除时，确认窗口打开期间所选内容保持固定，因此后台的手柄操作无法更改要删除的文件。
- 叠加层的删除对话框在打开期间会接管手柄输入，并在叠加层隐藏时关闭。
- 叠加层会跳过已停止响应的窗口，而不是等待它们。
- 切换回 GameHQ 后用鼠标滚动时，“设置”不再跳回顶部。
- 在手柄映射编辑器中选择“内置默认设置”或移除预设后，预设选择不再卡住。

## 手柄与 Playnite

- 在 Steam 之外启动的游戏（例如从 Playnite 启动的本地游戏）中，手柄快捷键仍可正常使用。当游戏处于焦点时，如果 Windows 停止将已连接的 DualSense 传递给 GameHQ，GameHQ 会以只读方式直接读取该手柄，并在 Windows 恢复传递后回到正常输入方式。
- 快捷键和按住按键时的重复操作，始终会在同一次按下的松开时结束，包括通过 GameInput 报告的松开，以及在按住按键时拔下手柄的情况。
- 已永久断开的手柄会被清理，HidHide 检查不再拖慢界面，GameInput 设备也只会在有变化时重新检查。
- 即使 Playnite 无法识别游戏的进程，Playnite 游戏仍能被正确识别。
- Windows 的 Xbox 全屏体验：当 Xbox 界面位于前台时，GameHQ 会使用从 Playnite 启动的游戏进行截图和录制片段。此外，当 Xbox 模式在登录时延迟了 GameHQ 的启动，以预发布版形式单独提供的 GameHQ Playnite Integration 0.4.13 也会启动 GameHQ。

## 稳定性与可靠性

- 清理未完成的录制时，只会删除 GameHQ 自己创建的临时文件。
- 游戏捕获文件夹始终位于你的捕获文件夹内。
- 媒体库包含重复的文件夹路径时，启动不再失败，而是会合并这些条目。
- 如果 GameHQ 无法启动，它会用你的语言说明原因，并将原因保留在日志中。
- 现在即使已安装的副本已经启动过，也能将便携配置文件导入已安装的 GameHQ。
- 安全性增强：更安全的 DLL 加载、对本地集成连接更严格的检查，以及更安全的更新文件处理。
- 更新程序能更好地应对首次启动缓慢的情况，并在被中断时保持其记录完整。
- Telegram 分享的关闭过程更加安全。

## 安装与更新

- 从 0.7.9 更新：直接在当前安装上运行 0.8.0 安装程序。
- 安装程序：为当前用户安装，并替换已安装的 0.7.9 或更早的测试版。
- 便携版：将 ZIP 解压到一个新文件夹，然后运行 GameHQ.exe。
- 如果你测试过 0.8.0 Beta 2、3 或 4，请使用安装程序或全新的便携版 ZIP 安装 0.8.0，因为这些测试版没有通过更新程序提供。

## 已知限制

- “游戏音频”需要 Windows 11。在较旧的 Windows 版本上，GameHQ 使用“桌面音频”，它也会录制在默认输出设备上播放的其他应用。
- 独占控制手柄的游戏仍可能使后台快捷键无法使用。
- 对 Windows 的 Xbox 全屏体验的支持，尚未经测试人员在运行该体验的 PC 上确认。
- Windows 二进制文件未经过 Authenticode 签名；Windows SmartScreen 可能会显示“未知发布者”警告。
